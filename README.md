This repository is associated with our manuscript:

**CMT-Diff: Cascaded Mean-Teacher Diffusion for Semi-Supervised Underwater Image Restoration**

## Overview

CMT-Diff is a semi-supervised diffusion framework for underwater image restoration. It combines a cascaded diffusion architecture with a mean-teacher learning strategy to use both labeled and unlabeled underwater images.
